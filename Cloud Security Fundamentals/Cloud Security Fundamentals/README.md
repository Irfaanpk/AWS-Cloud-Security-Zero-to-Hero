
# Cloud Security Fundamentals

## Overview

Cloud security is the practice of protecting cloud-based infrastructure, applications, data, and identities from unauthorized access, cyber threats, and data breaches.

It combines security policies, technical controls, and operational practices to maintain the confidentiality, integrity, and availability of cloud resources.

## 1. What Is Cloud Security?

Cloud security refers to the technologies, policies, and practices used to protect cloud environments and the resources hosted within them.

It includes:

- **Data Security:** Protecting sensitive information from unauthorized access, modification, or loss.
- **Identity Security:** Ensuring that only authorized users and services can access resources.
- **Infrastructure Security:** Protecting compute, storage, and networking resources.
- **Application Security:** Protecting applications against vulnerabilities and attacks.
- **Monitoring:** Identifying suspicious activities and potential security incidents.

## 2. Why Is Cloud Security Important?

- Protects sensitive business and customer data.
- Prevents unauthorized access to cloud resources.
- Reduces the risk of data breaches and service disruptions.
- Supports business continuity and service availability.
- Helps organizations meet compliance requirements.

## 3. Traditional IT Security vs. Cloud Security

| Aspect | Traditional IT Security | Cloud Security |
|--------|-------------------------|----------------|
| Infrastructure | Primarily organization-managed hardware | Cloud-provider infrastructure and customer-managed resources |
| Physical Security | Organization secures its facilities | Cloud provider secures its physical infrastructure |
| Resource Provisioning | Often requires manual provisioning | Resources can be provisioned on demand |
| Access Management | Local or enterprise identity systems | Cloud identities, roles, policies, and federation |
| Scalability | Depends on available infrastructure | Supports dynamic scaling |
| Responsibility | Depends on infrastructure ownership | Shared between provider and customer |

## 4. Major Areas of Cloud Security

| Area | Description |
|------|-------------|
| Identity Security | Controls access to cloud resources |
| Data Security | Protects data from unauthorized access and loss |
| Network Security | Controls network traffic and connectivity |
| Infrastructure Security | Protects compute, storage, and other resources |
| Application Security | Reduces application vulnerabilities |
| Threat Detection | Identifies suspicious activities and potential threats |
| Governance and Compliance | Establishes security policies and regulatory controls |

## 5. Common Cloud Security Challenges

- **Misconfiguration:** Incorrect settings that expose cloud resources.
- **Weak Access Controls:** Excessive permissions or insufficient authentication.
- **Data Exposure:** Sensitive information accessible to unauthorized users.
- **Credential Compromise:** Stolen passwords, access keys, or session credentials.
- **Limited Visibility:** Insufficient monitoring of cloud activities.
- **Compliance Risks:** Failure to meet applicable security and regulatory requirements.

## 6. Introduction to the Shared Responsibility Model

The shared responsibility model defines how security responsibilities are divided between the cloud provider and the customer.

- **Cloud Provider:** Secures the underlying infrastructure, physical facilities, and foundational services.
- **Customer:** Secures the resources and configurations they manage, including identities, permissions, data, and workloads.
- **Responsibility Varies:** The division depends on the cloud service model and the services being used.
